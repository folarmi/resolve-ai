# ResolveAI

ResolveAI is an AI-powered software incident diagnosis and management platform designed to help developers diagnose, investigate, and resolve software incidents faster.

## Project Status

Currently under development as an individual Software Engineering capstone project.

## Core Capabilities

- Software incident management
- AI-powered incident diagnosis
- Severity and category classification
- Root-cause suggestions
- Troubleshooting recommendations
- RAG-based runbook retrieval
- Incident history and resolution tracking
- Incident analytics
- AI diagnosis feedback
