# Network Troubleshooting Runbook

## Common Symptoms

- Connection refused
- Connection timeout
- DNS resolution failure
- Services cannot communicate
- Intermittent connectivity

## Common Causes

- Incorrect hostname or port
- DNS configuration problems
- Firewall rules
- Routing problems
- Service unavailable
- Network policy restrictions

## Investigation Steps

1. Verify hostname and port configuration.
2. Test DNS resolution.
3. Test connectivity to the destination host.
4. Check firewall and security rules.
5. Review routing configuration.
6. Verify the destination service is listening.

## Resolution

Correct DNS, firewall, routing, port, or service configuration based on the identified connectivity failure.
