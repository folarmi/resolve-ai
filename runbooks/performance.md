# Application Performance Troubleshooting Runbook

## Common Symptoms

- Slow API responses
- Request timeouts
- High CPU usage
- High memory usage
- Increased latency

## Common Causes

- Inefficient database queries
- Resource exhaustion
- Excessive application load
- Slow external dependencies
- Memory leaks
- Insufficient application capacity

## Investigation Steps

1. Review CPU and memory utilization.
2. Measure endpoint response times.
3. Identify slow database queries.
4. Check external dependency latency.
5. Review application logs.
6. Compare traffic with normal levels.
7. Check available application instances.

## Resolution

Optimize slow operations, resolve resource leaks, improve database queries, restore slow dependencies, or scale application capacity.
